# راه‌اندازی Nexus Game Booster 2.2.1

## فایل‌های مهم
- `app/` سورس Android نسخه 2.2.1
- `cloudflare-worker/nexus-gamebooster-api.js` کد کامل Worker
- `cloudflare-worker/admin-v1.0.html` پنل مدیریت اصلاح‌شده
- `cloudflare-worker/migration-v1.1.5-accounts-private-keys.sql` مهاجرت دیتابیس نسخه 1.1.5
- `cloudflare-worker/verify-v2.2.1.sql` بررسی ساختار دیتابیس بدون تغییر اطلاعات

## ترتیب به‌روزرسانی
1. از D1 یک Backup بگیرید.
2. در Cloudflare Worker، فایل `nexus-gamebooster-api.js` را جایگزین و Deploy کنید.
3. پنل HTML را با `admin-v1.0.html` جایگزین کنید.
4. اگر Migration نسخه 1.1.5 قبلاً اجرا شده است، آن را تکرار نکنید. اگر اجرا نشده، همان فایل Migration را فقط یک‌بار اجرا کنید.
5. مقدار Secret با نام `ADMIN_TOKEN` باید با توکن واردشده در پنل یکسان باشد. مقدار آن را در کد یا فایل عمومی قرار ندهید.
6. در مرورگر، پنل را با بارگذاری مجدد کامل باز کنید و API URL را بررسی کنید.
7. از صفحه ورود برنامه، صدور شماره‌حساب را آزمایش کنید. سپس همان شماره را در پنل برای ساخت کلید خصوصی وارد کنید.

## رفتار شماره‌حساب
- در اولین نمایش صفحه ورود، برنامه صدور شماره‌حساب را خودکار امتحان می‌کند.
- اگر شبکه در دسترس نباشد، دکمه «صدور شماره‌حساب اختصاصی» برای تلاش مجدد در دسترس است.
- شناسه نصب در حافظه خصوصی برنامه نگهداری می‌شود و API یک شماره ثابت برای همان نصب نگه می‌دارد.
- پاک کردن داده‌های برنامه یا نصب مجدد ممکن است شناسه نصب جدید بسازد؛ برای بازیابی حساب قبلی، داده‌های برنامه را پاک نکنید.

## آزمون کلید
1. ابتدا یک حساب در برنامه صادر کنید؛ قالب `User-XXXXX` است.
2. شماره حساب را در بخش کلید خصوصی پنل وارد و کلید بسازید.
3. برای کلید عمومی، نیازی به شماره‌حساب نیست.
4. کلید خصوصی فقط برای همان حساب پذیرفته می‌شود.
5. کلیدها هنگام هش‌سازی نرمال می‌شوند؛ بزرگ یا کوچک بودن حروف ورودی باعث عدم تطابق نمی‌شود.

## عیب‌یابی
- `401`: مقدار `ADMIN_TOKEN` در پنل با Worker Secret یکسان نیست.
- `no such table: customer_accounts`: Migration اجرا نشده است.
- `no such column: key_plain` یا `key_type` یا `account_code`: Migration ناقص/اجرا نشده است.
- `account_not_found`: کاربر هنوز شماره‌حسابش را از همان نصب برنامه صادر نکرده یا شماره را اشتباه وارد کرده است.
- `ACCOUNT_MISMATCH`: کلید خصوصی برای شماره‌حساب دیگری صادر شده است.

## محدودیت آزمون
Worker و پنل از نظر Syntax بررسی شده‌اند و عملیات SQL روی SQLite آزمایشی اجرا شده است. این بسته به‌تنهایی Worker را روی حساب Cloudflare شما Deploy نمی‌کند و APK نهایی در این محیط ساخته نشده است. برای تأیید نهایی، Worker باید Deploy شود و با D1 واقعی آزمایش گردد.
