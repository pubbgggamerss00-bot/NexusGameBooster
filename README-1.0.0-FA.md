# Nexus Game Booster 1.0.0 — راه‌اندازی تیکت‌ها

## فایل‌ها
- `cloudflare-worker/nexus-gamebooster-api.js`: API نسخه 1.0.0
- `cloudflare-worker/migration-v1.0-support-tickets.sql`: مهاجرت دیتابیس D1
- `cloudflare-worker/admin-v1.0.html`: پنل ادمین با مدیریت تیکت، تمدید کلید و کلید تستی ساعتی

## ترتیب نصب
1. از دیتابیس D1 نسخه پشتیبان بگیرید.
2. migration SQL را یک بار اجرا کنید.
3. کد API جدید را در Worker Deploy کنید و مطمئن شوید binding با نام `DB` و secret با نام `ADMIN_TOKEN` باقی مانده‌اند.
4. پنل HTML جدید را باز کنید و با توکن ادمین وصل شوید.
5. سورس اندروید را در محیط Android/Gradle بسازید و نصب کنید.
6. تست کنید: کلید اشتباه باید رد شود؛ کلید نشست فعال باید فرم تیکت را باز کند؛ پاسخ ادمین باید در «تیکت‌های من» دیده شود.

## وضعیت تیکت‌ها
- `open`: منتظر بررسی/پاسخ
- `answered`: پاسخ پشتیبانی ثبت شده
- `rejected`: رد شده؛ پاسخ کاربر بسته است
- `closed`: بسته؛ پاسخ کاربر بسته است

کلیدهای روزانه قبلی همچنان کار می‌کنند. کلید تستی ساعتی با ارسال `hours: 1` ایجاد می‌شود. تمدید با `hours` یا `days` اعتبار موجود را از بیشینه زمان فعلی و اکنون ادامه می‌دهد.
