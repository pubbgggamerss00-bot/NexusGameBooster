Nexus Game Booster 1.2.1 (Arcade Edition) — full redesign!

What's new:
• Complete arcade redesign of every screen: chamfered neon panels, 3D "lip" buttons, HUD gauges, segmented controls and skewed stat bars — exactly like the redesign mockup.
• New arcade ambience: a retro perspective floor grid, drifting neon glows and a green scan sweep when you switch screens.
• Home: the boost button is now a glowing REACTOR — spinning orbit ring, tick dial, hexagonal core with press-down 3D feel, step badges and a celebration particle burst when the boost finishes.
• Bottom navigation rebuilt: sliding indicator, icons that pop up when selected.
• Monitor: dashboard ring gauges (battery / memory) with animated arcs in the HUD font.
• Profiles: selected profile card scales up with a neon glow, animated stat pips.
• Better ping: power-style connection ring for WireGuard and colored signal bars for each DNS server.
• New fonts: Vazirmatn (body), Rajdhani (HUD digits), Orbitron (tags) — full Persian support.
• Every animation respects "Reduce motion" and your system animation setting.

Fixed in this release:
• The 1.2.0 release APK itself was healthy — if it did not install on your phone, it was because your installed copy is signed with an older key that no longer exists (previous signing keys were lost). From 1.2.1 the app uses a NEW permanent signing key that is stored with the project, so all future updates install as normal updates without uninstalling.
• One-time step for this version only: uninstall the old app once, then install 1.2.1. After that, updates install directly.

Version: 1.2.1 (versionCode 28)
