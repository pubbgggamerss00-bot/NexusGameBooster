Nexus Game Booster 1.1.3 — new version!

What's new:
• New optional ROOT game mode in Settings: check root access, then set Android's GameManager performance mode for a game package (or restore standard mode).
• Safety first: root is only requested when YOU tap a button, the package name is strictly validated, only the two fixed GameManager commands are used, and the real output/errors are shown — success is never faked.
• Honest limits: your ROM must support GameManager mode; no FPS gain is promised. Devices without root are unaffected.
• One new settings card, localized in English and Persian; 2 new unit tests (112 total). No new permissions.
• Updating from 1.1.2 (or any 0.11.3+) installs directly — no uninstall needed (same signature).
