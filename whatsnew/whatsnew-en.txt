Nexus Game Booster — new version!

What's new:
• The app now comes pre-connected to the official Nexus server — you only enter your access key, nothing else.
• One-time sign-in: after that the app stays connected and re-checks itself automatically on every start.
• The server address is still there for advanced users under "Change server address" — you never have to touch it.
• Wrong or used-up key? The server now answers with a clear message instead of a generic error.

Updating: if you are on 0.11.1, install this update directly — no uninstall needed. (Only installs older than 0.11.1 need the one-time uninstall first.)

Still inside the app: the "Check for updates" button in Settings, plain-language release notes, and one-tap download & install — everything stays in the app.
