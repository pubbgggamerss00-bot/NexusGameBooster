Nexus Game Booster — new version!

What's new:
• The license screen is now simpler than ever: the app always talks to the official Nexus server and only asks for your access key — the server address field is completely gone.
• Wrong key shows in red, successful activation in green.

IMPORTANT — read before updating:
• This update changes the app's signing key (the old one was lost and cannot be recovered). Because of that, the app CANNOT install over the old version directly.
• How to update: uninstall the old Nexus Game Booster first, then install the new APK, then enter your access key once — that's it.
• After this one-time change, future updates will install directly again, no uninstall needed.
