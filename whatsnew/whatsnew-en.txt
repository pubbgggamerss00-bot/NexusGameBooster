Nexus Game Booster 1.1.1 — new version!

What's new:
• Library, Monitor, Profiles and Settings now share one clean neon page header — every main screen looks consistent.
• DNS forwarding stability fix: if the DNS forwarder hits an input/output error it now stops cleanly instead of retrying forever, and the "connected" status can no longer go stale after a failure.
• Nothing else changed — no new permissions, no API or account changes.
• Updating from 1.1.0 (or any 0.11.3+) installs directly — no uninstall needed (same signature).
